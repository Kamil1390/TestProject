## Эндпоинты
В приложении имеется три эндпоинта:
### POST /create
Предназначен для добавления в БД новой записи об инциденте.
В теле запроса нужно указать:
1. description. Описание инцидента
2. status. Статус инцидента. Принимает только два значения - active и dont_active
3. source. Источник

Оставшиеся два значения - id и daterecord - создаются автоматически
В результате удачного выполнения будет возвращен id созданного инцидента

Пример:
![create](docs/img/create.png)

### GET /get_incidents/{status_active}
Предназначен для получения списка инцидентов (с фильтром по статусу).
Статус может принимать только два значения - active и dont_active.
В результате будет выведен список инцидентов с указанным статусом

Пример:
![get info](docs/img/get_1.png)

### PATCH /update
Предназначен для обновления статуса инцидента по id. Принимает два параметра -
id инцидента и новый статус. В случае успешного обновления будет получено 
соответствующее сообщение со статусом 200. Если указанного id нет в БД - будет
полученно сообщение со статусом 404.

Пример успешного обновления:
